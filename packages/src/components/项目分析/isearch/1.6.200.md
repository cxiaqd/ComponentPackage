## 二、架构设计

### 1. 目录结构

```
isearch-frontend/src/
├── api/              # API接口层
├── assets/           # 静态资源
├── components/       # 公共组件
├── core/             # 核心功能
│   ├── httpInstance.js    # HTTP请求封装
│   ├── initApp.js         # 应用初始化
│   ├── huiPro.js          # UI组件引入
│   └── wistom-base.js     # 基础配置
├── i18n/             # 国际化
├── mixins/           # Vue混入
├── pages/            # 页面组件
│   ├── home/              # 首页
│   ├── imgResult/         # 以图搜图
│   ├── wordSearch/        # 文本搜索
│   ├── fusionResult/      # 融合搜索
│   ├── advancedSearch/    # 高级搜索
│   ├── portraitSearch/    # 人像搜索
│   └── ...
├── plugin/           # 插件
├── router/           # 路由配置
├── store/            # 状态管理
├── style/            # 样式文件
└── utils/            # 工具函数
```

### 2. 分层架构

| 层级 | 说明 | 关键文件 |
|------|------|----------|
| 入口层 | 应用启动入口 | [`main.js`](isearch-frontend/src/main.js:1) |
| 路由层 | 动态路由加载 | [`router/index.js`](isearch-frontend/src/router/index.js:17) |
| 状态层 | Vuex状态管理 | [`store/index.js`](isearch-frontend/src/store/index.js:11) |
| 网络层 | HTTP请求封装 | [`core/httpInstance.js`](isearch-frontend/src/core/httpInstance.js:20) |
| 业务层 | 页面组件 | [`pages/`](isearch-frontend/src/pages) |
| 组件层 | 公共组件 | [`components/`](isearch-frontend/src/components) |

### 3. 路由配置

采用动态导入实现路由懒加载：

```javascript
// router/index.js (行17)
component: () => import(`@/pages/${component}`)
```

支持的路由：
- `/home` - 首页
- `/image` - 以图搜图
- `/text` - 文本搜索
- `/attr` - 属性搜索
- `/fusion` - 融合搜索
- `/portrait` - 人像搜索
- `/mapPage` - 地图页面
- `/1v1` - 对比页面

## 五、性能优化

### 1. 代码层面

| 优化手段 | 实现方式 |
|----------|----------|
| 路由懒加载 | `component: () => import()` 动态导入 |
| 组件异步加载 | 微前端 hel-micro 远程加载 |
| 图片懒加载 | 骨架屏 skeleton-loader |

### 2. 构建层面

- **Gzip压缩**: 阈值10KB，压缩js/css
- **Chunk合并**: 最多5个chunk
- **Tree Shaking**: 按需引入组件
- **CDN资源**: 静态资源走CDN

### 3. 网络层面

- **HTTP/2**: 开发环境配置
- **代理配置**: 开发环境多接口代理
- **请求合并**: 批量请求优化

## 八、总结

USTA-iSearch 是一个**海康威视旗下的智能搜索系统**，具有以下特点：

1. **技术成熟**: 基于Vue 2 + Vuex + Vue Router的经典Vue技术栈
2. **组件丰富**: 深度定制的海康UI组件库，涵盖图像、地图、车辆等多种业务组件
3. **架构清晰**: 分层设计，模块化开发，易于维护扩展
4. **性能优化**: 多种优化手段，包括懒加载、压缩、代码分割
5. **微前端探索**: 引入hel-micro实现模块的远程加载
6. **国际化支持**: 完整的中英文国际化方案
7. **工程化完善**: ESLint、Prettier、Git hooks等开发工具齐全
