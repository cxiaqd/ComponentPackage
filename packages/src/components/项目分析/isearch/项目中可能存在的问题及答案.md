## 一、Vue 框架相关

### 问题 1：Vue 2.7 相比 Vue 2 早期版本有哪些重要更新？你在项目中如何应用这些特性？

**参考答案：**

Vue 2.7 是 Vue 2 的最后一个大版本，主要更新包括：

1. **Composition API 内置支持**
   - Vue 2.7 将原本在 Vue 3 中的 Composition API 向后移植到 Vue 2
   - 无需再安装 `@vue/composition-api` 插件
   - 可以直接使用 `setup()`、`ref()`、`reactive()` 等 API

2. **`<script setup>` 语法糖支持**
   - 更简洁的组合式 API 写法
   - 自动导入组件和变量
   - 更好的 TypeScript 支持

3. **响应式系统优化**
   - 改用了 Vue 3 的部分响应式实现
   - 性能有所提升

**项目中的应用：**
```javascript
// 本项目主要使用 Options API
export default {
  data() {
    return {
      searchResult: [],
      loading: false
    }
  },
  methods: {
    async handleSearch() {
      this.loading = true
      try {
        const res = await this.$http.get({ url: '/search' })
        this.searchResult = res.data
      } finally {
        this.loading = false
      }
    }
  }
}
```

### 问题 2：Vue 的响应式原理是什么？有什么局限性？

**参考答案：**

**Vue 2 响应式原理：**

1. **Object.defineProperty 劫持**
   - 通过 `Object.defineProperty()` 劫持对象属性的 getter 和 setter
   - 在 getter 中收集依赖（订阅者）
   - 在 setter 中通知更新（发布）

2. **依赖收集过程**
   ```
   组件渲染 → 读取数据 → 触发 getter → 收集 Watcher → 数据变化 → 触发 setter → 通知 Watcher → 视图更新
   ```

3. **数组响应式**
   - 重写数组的 7 个变更方法：push、pop、shift、unshift、splice、sort、reverse
   - 通过这些方法触发视图更新

**局限性：**

1. **无法检测对象属性的添加或删除**
   ```javascript
   // 无效
   this.obj.newProp = 'value'
   // 需要使用 Vue.set
   this.$set(this.obj, 'newProp', 'value')
   ```

2. **无法检测数组索引和长度的直接修改**
   ```javascript
   // 无效
   this.arr[0] = 'newValue'
   this.arr.length = 0
   // 需要使用 splice
   this.arr.splice(0, 1, 'newValue')
   ```

3. **性能问题**
   - 初始化时需要递归遍历所有属性
   - 深层嵌套对象性能较差

### 问题 4：Vue 的生命周期有哪些？在哪个阶段适合发起 API 请求？

**参考答案：**

**Vue 2 生命周期：**

```
beforeCreate → created → beforeMount → mounted → beforeUpdate → updated → beforeDestroy → destroyed
```

**各阶段说明：**

| 钩子 | 说明 | 适用场景 |
|------|------|----------|
| beforeCreate | 实例初始化后，数据观测和事件配置之前 | 几乎不用 |
| created | 实例创建完成，数据观测完成，DOM 未生成 | **发起 API 请求** |
| beforeMount | 模板编译完成，即将挂载 | 几乎不用 |
| mounted | DOM 挂载完成 | DOM 操作、第三方库初始化 |
| beforeUpdate | 数据更新，视图更新前 | 获取更新前的 DOM |
| updated | 视图更新完成 | 操作更新后的 DOM |
| beforeDestroy | 实例销毁前 | 清理定时器、事件监听 |
| destroyed | 实例销毁完成 | 清理工作 |

**项目中的实践：**

```javascript
// 在 created 中发起请求
export default {
  data() {
    return {
      tableData: [],
      loading: false
    }
  },
  created() {
    this.fetchData()
  },
  mounted() {
    // 初始化地图
    this.initMap()
  },
  beforeDestroy() {
    // 清理定时器
    clearInterval(this.timer)
    // 销毁地图实例
    this.map && this.map.destroy()
  },
  methods: {
    async fetchData() {
      this.loading = true
      try {
        const res = await this.$http.get({ url: '/api/data' })
        this.tableData = res.data
      } finally {
        this.loading = false
      }
    }
  }
}
```

### 问题 5：Vue 的虚拟 DOM 是如何工作的？diff 算法的原理是什么？

**参考答案：**

**虚拟 DOM 工作原理：**

1. **虚拟节点（VNode）**
   - 用 JavaScript 对象描述 DOM 结构
   - 包含 tag、props、children 等属性

2. **渲染过程**
   ```
   template → render 函数 → VNode → 真实 DOM
   ```

3. **更新过程**
   ```
   数据变化 → 重新 render → 新 VNode → diff 对比 → 最小化更新真实 DOM
   ```

**diff 算法原理：**

1. **同层比较**
   - 只比较同一层级的节点
   - 时间复杂度 O(n)

2. **key 的作用**
   - 通过 key 快速定位相同节点
   - 避免不必要的 DOM 操作

3. **diff 策略**
   - 节点类型不同，直接替换
   - 节点类型相同，比较属性
   - 列表使用 key 进行复用

**项目中的优化：**

```vue
<!-- 列表渲染必须加 key -->
<template>
  <div v-for="item in list" :key="item.id">
    {{ item.name }}
  </div>
</template>

<!-- 避免使用 index 作为 key -->
<!-- ❌ 错误写法 -->
<div v-for="(item, index) in list" :key="index">

<!-- ✅ 正确写法 -->
<div v-for="item in list" :key="item.uniqueId">
```

### 问题 7：Vuex 的 state、mutations、actions 有什么区别？

**参考答案：**

| 特性 | state | mutations | actions |
|------|-------|-----------|---------|
| 作用 | 存储状态 | 修改状态 | 处理异步 |
| 同步/异步 | - | 必须同步 | 可以异步 |
| 调用方式 | this.$store.state.xxx | this.$store.commit('xxx') | this.$store.dispatch('xxx') |
| 参数 | - | 最多一个参数 | 最多一个参数 |
| 返回值 | - | 无要求 | 返回 Promise |

**代码示例：**

```javascript
// store.js
export default new Vuex.Store({
  state: {
    count: 0,
    userInfo: null
  },
  mutations: {
    // 同步修改
    increment(state, payload) {
      state.count += payload.amount
    },
    setUser(state, user) {
      state.userInfo = user
    }
  },
  actions: {
    // 异步操作
    async fetchUser({ commit }, userId) {
      const { data } = await api.getUser(userId)
      commit('setUser', data)
    },
    // 多个 mutations
    async login({ commit }, credentials) {
      try {
        const { data } = await api.login(credentials)
        commit('setUser', data.user)
        commit('setToken', data.token)
        return Promise.resolve(data)
      } catch (error) {
        return Promise.reject(error)
      }
    }
  }
})
```

     mode: 'hash',

     mode: 'history',
     base: process.env.BASE_URL,
     routes: [...]
   })

   - URL 美观：`http://example.com/home`
   - 需要后端配置支持
   - 现代浏览器支持

### 问题 10：项目中是如何封装 Axios 的？拦截器有什么作用？

**参考答案：**

**项目中的 Axios 封装：**

```javascript
// core/httpInstance.js
import axios from 'axios'
import { Message } from 'hui'
import i18n from '@/i18n'

const http = axios.create({
  timeout: 180000,
  withCredentials: true,
  baseURL: `${process.env.VUE_APP_CONTEXT}${process.env.VUE_APP_API_PREFIX}/`
})

// 请求拦截器
http.interceptors.request.use(
  config => {
    // 添加时间戳防止缓存
    if (config.method === 'get') {
      config.params = {
        ...config.params,
        _t: Date.now()
      }
    }
    // 添加 API 后缀
    config.url += config.withoutSuffix ? '' : process.env.VUE_APP_API_SUFFIX
    return config
  },
  error => Promise.reject(error)
)

// 响应拦截器
http.interceptors.response.use(
  response => {
    // 处理业务错误
    if (response.data.type !== 0) {
      if (!response.config.errorNotNotify) {
        showError(response.data)
      }
    }
    return Promise.resolve(response.data)
  },
  error => {
    const response = error.response
    // 401/403 重新登录
    if (response.status === 401 || response.status === 403) {
      window.location.reload()
    }
    return Promise.reject(error)
  }
)

// 统一 API 方法
export default {
  get(opts) {
    return http({ method: 'get', ...opts })
  },
  post(opts) {
    return http({ method: 'post', ...opts })
  },
  upload(opts) {
    return http({ 
      method: 'post',
      headers: { 'Content-Type': 'multipart/form-data' },
      ...opts 
    })
  },
  download(opts) {
    return http({ method: 'get', responseType: 'blob', ...opts })
  }
}
```

**拦截器的作用：**

1. **请求拦截器**
   - 添加认证 token
   - 添加请求参数
   - 请求 loading
   - 统一错误处理

2. **响应拦截器**
   - 统一错误提示
   - 数据格式转换
   - 登录过期处理
   - 响应 loading 关闭

### 问题 11：如何处理多个并发请求？

**参考答案：**

**方法一：Promise.all**
```javascript
async function initData() {
  try {
    const [configRes, userRes, dicRes] = await Promise.all([
      this.$http.get({ url: '/config' }),
      this.$http.get({ url: '/user' }),
      this.$http.get({ url: '/dic' })
    ])
    this.config = configRes.data
    this.user = userRes.data
    this.dic = dicRes.data
  } catch (error) {
    console.error('初始化失败', error)
  }
}
```

**方法二：async/await 串行**
```javascript
async function initData() {
  const configRes = await this.$http.get({ url: '/config' })
  const userRes = await this.$http.get({ url: '/user' })
  const dicRes = await this.$http.get({ url: '/dic' })
}
```

**方法三：Promise.allSettled（不阻断）**
```javascript
const results = await Promise.allSettled([
  this.$http.get({ url: '/api1' }),
  this.$http.get({ url: '/api2' })
])
results.forEach((result, index) => {
  if (result.status === 'fulfilled') {
    console.log(`请求${index}成功`, result.value)
  } else {
    console.log(`请求${index}失败`, result.reason)
  }
})
```
