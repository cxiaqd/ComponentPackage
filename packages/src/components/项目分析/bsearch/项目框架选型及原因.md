## 一、核心技术栈

### 1.1 前端框架：Vue 2.7.x

**选型原因：**

```
┌─────────────────────────────────────────────────────────────┐
│                  选择 Vue 2.7.x 的原因                        │
└─────────────────────────────────────────────────────────────┘

1. 企业级应用需求
   ├── 成熟的生态系统
   ├── 丰富的组件库（HUI、Element UI）
   ├── 完善的文档和社区支持
   └── 大量企业级应用案例

2. 团队技术栈
   ├── 团队成员熟悉 Vue 技术栈
   ├── 降低学习成本
   ├── 提高开发效率
   └── 便于代码维护

3. 项目需求匹配
   ├── 复杂的单页应用（SPA）
   ├── 大量的交互操作
   ├── 需要组件化开发
   └── 需要响应式数据绑定

4. 性能考虑
   ├── 虚拟 DOM 提升渲染性能
   ├── 组件懒加载减少首屏时间
   ├── 计算属性缓存优化
   └── 适合大数据量场景

5. 兼容性要求
   ├── 支持 IE11+
   ├── 良好的浏览器兼容
   ├── Polyfill 支持完善
   └── 适合企业内网环境
```

```javascript
const http = axios.create({
  timeout: 180000,
  withCredentials: true,

    'X-CSRF-TOKEN': getToken()
  }
});

// 请求拦截器

  if (config.method === 'get') {
    config.params = { ...config.params, _t: Date.now() };
  }
  return config;
});

// 响应拦截器
http.interceptors.response.use(
  response => {
    if (response.data.code !== '0') {
      showError(response.data);
    }
    return response.data;
  },
  error => {
    if (error.response?.status === 401) {
      window.location.reload();
    }
    return Promise.reject(error);
  }

```

```
│                    框架对比表                                │
└─────────────────────────────────────────────────────────────┘

学习曲线      | 低           | 中          | 高
```

#### 场景4：封装多种请求方法

**代码位置：** [`core/httpInstance.js`](bsearch-frontend/search-center/src/core/httpInstance.js:132-240)

```javascript
export default {
  get(opts) {
    return new Promise((resolve, reject) => {
      const params = {
        method: 'get'
      };
      http(merge(params, opts))
        .then(res => {
          resolve(res);
        })
        .catch(err => {
          reject(err);
        });
    });
  },
  post(opts) {
    return new Promise((resolve, reject) => {
      const params = {
        method: 'post',
        headers: {
          'Content-Type': 'application/json'
        }
      };
      http(merge(params, opts))
        .then(res => {
          resolve(res);
        })
        .catch(err => {
          reject(err);
        });
    });
  },
  upload(opts) {
    if (getToken() !== '') {
      opts.url += `?_csrf=${getToken()}`;
    }
    const params = {
      method: 'post',
      headers: {
        'Content-Type': 'multipart/form-data'
      }
    };
    return new Promise((resolve, reject) => {
      http(merge(params, opts))
        .then(res => {
          resolve(res);
        })
        .catch(err => {
          reject(err);
        });
    });
  },
  download(opts) {
    return new Promise((resolve, reject) => {
      let newParams = {
        method: 'get',
        responseType: 'blob'
      };
      newParams = merge(newParams, opts);
      http(newParams)
        .then(res => {
          const blob = new Blob([res]);
          if (res.type.indexOf('json') > -1) {
            // 处理 JSON 错误响应
            const newblob = blob.slice(0, blob.size);
            const reader = new FileReader();
            reader.readAsText(newblob, 'utf-8');
            reader.onload = function(evt) {
              if (evt.target.readyState === FileReader.DONE) {
                const result = JSON.parse(evt.target.result);
                result.traceCode = res.traceCode;
                if (result.type === -1) {
                  Message.error(result.msg);
                } else if (result.type === -2) {
                  showError(result);
                }
              }
            };
          } else {
            // 处理文件下载
            const { params } = newParams;
            if (params.ext) {
              params.type = params.ext;
            }
            if (params.type === 'excel') {
              params.type = 'xlsx';
            }
            const fileName = `${params.fileName}.${params.type}`;
            if ('download' in document.createElement('a')) {
              // 非IE下载
              const elink = document.createElement('a');
              elink.download = fileName;
              elink.style.display = 'none';
              elink.href = URL.createObjectURL(blob);
              document.body.appendChild(elink);
              elink.click();
              URL.revokeObjectURL(elink.href); // 释放URL 对象
              document.body.removeChild(elink);
            } else {
              /** IE10+下载**/
              navigator.msSaveBlob(blob, fileName);
            }
          }
          resolve(res);
        })
        .catch(err => {
          reject(err);
        });
    });
  }
};
```

**为什么选择 Axios：**
- **多种请求方法**：封装 get、post、upload、download 四种方法
- **文件上传**：支持 multipart/form-data，自动添加 CSRF token
- **文件下载**：支持 blob 响应，自动处理文件下载
- **跨浏览器兼容**：支持 IE10+ 的下载方式
- **错误处理**：统一的错误处理机制

## 六、技术选型对比总结

### 6.1 为什么不选择其他方案

```
┌─────────────────────────────────────────────────────────────┐
│              技术选型对比分析                                │
└─────────────────────────────────────────────────────────────┘

1. Vue vs React vs Angular
   ├── Vue: 学习曲线低、团队熟悉、HUI 组件库基于 Vue
   ├── React: 学习曲线较高、团队不熟悉、HUI 不支持
   └── Angular: 学习曲线高、过重、HUI 不支持

2. Vuex vs Pinia vs Redux
   ├── Vuex: Vue 官方推荐、团队熟悉、适合中大型项目
   ├── Pinia: Vue 3 推荐、本项目使用 Vue 2.x
   └── Redux: React 生态、Vue 集成复杂

3. Axios vs Fetch vs SuperAgent
   ├── Axios: 功能完善、拦截器、错误处理、团队熟悉
   ├── Fetch: 原生 API、功能简单、需要封装
   └── SuperAgent: 功能完善、但不如 Axios 流行

4. Vue Router vs React Router vs Angular Router
   ├── Vue Router: Vue 官方推荐、API 简洁、团队熟悉
   ├── React Router: React 生态、Vue 不适用
   └── Angular Router: Angular 生态、Vue 不适用

5. HUI vs Element UI vs Ant Design Vue
   ├── HUI: 企业内部、视频监控组件、地图组件、符合设计规范
   ├── Element UI: 开源、但缺乏视频监控组件
   └── Ant Design Vue: 开源、但缺乏视频监控组件
```
