**初始化CSS样式**，是指通过编写一段全局CSS代码，手动将所有HTML元素的默认样式（如内外边距、边框、字体大小、盒模型等）重置为一个统一、可预测的基础状态。

---

### 为什么要初始化CSS样式？

#### 1. **消除浏览器默认样式差异**
不同浏览器（Chrome、Firefox、Safari、Edge等）对同一HTML元素的默认样式实现并不相同。例如：
- `<body>` 的 `margin` 默认值，有的浏览器是 `8px`，有的是 `0`。
- `<h1>` 的字体大小、粗细、上下边距各异。
- `<ul>` 的 `padding-left` 在有的浏览器中是 `40px`，有的是 `0`。

如果不初始化，同一个页面在不同浏览器下可能出现布局错位、间距不一致等问题。

#### 2. **获得可预测的布局基础**
初始化后，开发者可以从一个“空白画布”开始设计，而不是在浏览器默认样式之上进行“修补式”覆盖。这能：
- 避免因默认样式导致的意外布局偏移
- 让元素尺寸、间距完全由开发者定义的样式控制

#### 3. **简化响应式与盒模型计算**
通过 `box-sizing: border-box` 的全局设置（常见于初始化代码中），可以让元素的宽高包含内边距和边框，极大简化百分比布局时的尺寸计算。

#### 4. **提升开发效率与代码可维护性**
统一的初始状态意味着：
- 不需要反复重置特定元素的默认样式
- 团队协作时，样式基准一致
- 避免因浏览器更新导致默认样式变化而引发的兼容性问题

---

### 常见的初始化方式

**1. 简单版（最常用）**
```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```
- 优点：简单粗暴，覆盖所有元素
- 缺点：通配符选择器性能略低（现代浏览器中可忽略），且可能影响某些需要默认边距的替换元素（如按钮、表单）的显示

**2. 更精细的初始化（推荐）**
```css
*,
*::before,
*::after {
  box-sizing: border-box;
}

body,
h1, h2, h3, h4, p,
figure, blockquote, dl, dd,
ul, ol, li {
  margin: 0;
  padding: 0;
}

ul, ol {
  list-style: none;
}

a {
  text-decoration: none;
  color: inherit;
}

img {
  max-width: 100%;
  display: block;
}
```

**3. 成熟的第三方重置方案**
- **normalize.css**：保留有用默认样式，只修正浏览器不一致处（非完全重置，更温和）
- **modern-normalize**：轻量版normalize
- **sanitize.css**：更现代的默认样式统一方案

---

### 总结

初始化CSS样式是前端开发中的**最佳实践**之一。它的核心目标是**跨浏览器一致性**、**可预测的布局**以及**降低样式维护成本**。无论使用简单重置还是成熟的第三方库，都应作为每个项目的样式起点。
