## 媒体查询核心语法总结

### 1. 基础语法结构

```css
/* 标准语法 */
@media media-type and (media-feature) {
    /* CSS 规则 */
}

/* 常用示例 */
@media screen and (min-width: 768px) {
    .container {
        width: 750px;
    }
}
```

### 2. 媒体类型

| 类型 | 说明 |
|------|------|
| `all` | 所有设备（默认） |
| `screen` | 屏幕设备（电脑、手机、平板） |
| `print` | 打印预览模式 |
| `speech` | 屏幕阅读器 |

### 3. 常用媒体特性

| 特性 | 说明 | 示例 |
|------|------|------|
| `min-width` | 最小宽度 | `(min-width: 768px)` |
| `max-width` | 最大宽度 | `(max-width: 480px)` |
| `orientation` | 屏幕方向 | `(orientation: landscape)` |
| `min-height` | 最小高度 | `(min-height: 600px)` |
| `resolution` | 分辨率 | `(min-resolution: 192dpi)` |
| `hover` | 是否支持悬停 | `(hover: hover)` |
| `pointer` | 指针精度 | `(pointer: coarse)` |

### 4. 逻辑运算符

```css
/* AND 运算：同时满足多个条件 */
@media screen and (min-width: 768px) and (max-width: 1024px) {
    /* 平板设备 */
}

/* OR 运算：使用逗号分隔 */
@media (min-width: 768px), (orientation: landscape) {
    /* 宽度≥768px 或 横屏模式 */
}

/* NOT 运算：排除条件 */
@media not screen and (max-width: 768px) {
    /* 非屏幕设备且宽度>768px */
}
```

### 5. 常见断点参考

```css
/* 移动端（手机） */
@media (max-width: 767px) { }

/* 平板竖屏 */
@media (min-width: 768px) and (max-width: 1023px) { }

/* 平板横屏 / 小笔记本 */
@media (min-width: 1024px) and (max-width: 1279px) { }

/* 桌面显示器 */
@media (min-width: 1280px) and (max-width: 1439px) { }

/* 大屏显示器 */
@media (min-width: 1440px) { }
```

### 6. 两种策略对比

| 策略 | 语法 | 特点 | 适用场景 |
|------|------|------|----------|
| **移动优先** | `@media (min-width: 768px)` | 默认写移动端样式，通过 min-width 逐步增强 | 现代开发推荐 |
| **桌面优先** | `@media (max-width: 768px)` | 默认写桌面端样式，通过 max-width 逐步降级 | 旧项目改造 |
