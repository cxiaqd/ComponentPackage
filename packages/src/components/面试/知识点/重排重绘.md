重排（Reflow）和重绘（Repaint）是浏览器渲染过程中的关键环节。理解它们的触发时机和优化方法，对前端性能优化至关重要。

## 一、触发时机

### 1. **重排（Reflow）触发时机**
重排是指浏览器需要重新计算元素的位置和几何信息。

#### 常见触发场景：
```javascript
// 1. DOM操作
// 添加、删除、修改DOM元素
const div = document.createElement('div');
document.body.appendChild(div); // 触发重排

// 2. 几何属性变化
element.style.width = '200px';   // 宽度变化
element.style.height = '100px';  // 高度变化
element.style.margin = '10px';   // 边距变化
element.style.padding = '5px';   // 内边距变化
element.style.border = '1px solid red'; // 边框变化

// 3. 位置属性变化
element.style.position = 'absolute';
element.style.top = '10px';
element.style.left = '20px';

// 4. 字体变化
element.style.fontSize = '16px';
element.style.fontFamily = 'Arial';

// 5. 窗口尺寸变化
window.addEventListener('resize', () => {
  // 每次resize都会触发重排
});

// 6. 读取某些属性
const width = element.offsetWidth;      // 强制重排
const height = element.offsetHeight;    // 强制重排
const top = element.offsetTop;          // 强制重排
const clientRect = element.getBoundingClientRect(); // 强制重排
```

### 2. **重绘（Repaint）触发时机**
重绘是指浏览器重新绘制元素的视觉样式，但不影响布局。

#### 常见触发场景：
```javascript
// 1. 颜色属性变化
element.style.color = 'red';        // 文字颜色
element.style.backgroundColor = 'blue'; // 背景色
element.style.borderColor = 'green';    // 边框颜色

// 2. 可见性变化
element.style.visibility = 'hidden';

// 3. 背景图变化
element.style.backgroundImage = 'url(...)';

// 4. outline属性
element.style.outline = '1px solid red';
```

**注意**：重排一定会触发重绘，但重绘不一定会触发重排。

## 二、优化方法

### 1. **批量修改样式**
```javascript
// ❌ 不好的做法 - 多次触发重排
const element = document.getElementById('box');
element.style.width = '100px';
element.style.height = '100px';
element.style.margin = '10px';
element.style.padding = '5px';

// ✅ 好的做法 - 使用class一次性修改
const element = document.getElementById('box');
element.classList.add('new-style');

// ✅ 或者使用cssText
element.style.cssText = 'width: 100px; height: 100px; margin: 10px; padding: 5px;';
```

### 2. **使用DocumentFragment批量操作DOM**
```javascript
// ❌ 不好的做法 - 多次插入导致多次重排
const ul = document.getElementById('list');
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  ul.appendChild(li); // 每次appendChild都触发重排
}

// ✅ 好的做法 - 使用DocumentFragment
const ul = document.getElementById('list');
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  fragment.appendChild(li);
}
ul.appendChild(fragment); // 只触发一次重排
```

### 3. **缓存布局信息**
```javascript
// ❌ 不好的做法 - 每次循环都读取布局信息
for (let i = 0; i < elements.length; i++) {
  elements[i].style.width = container.offsetWidth + 'px'; // 每次都强制重排
}

// ✅ 好的做法 - 先读取，再批量修改
const containerWidth = container.offsetWidth; // 读取一次
for (let i = 0; i < elements.length; i++) {
  elements[i].style.width = containerWidth + 'px';
}
```

### 4. **分离读写操作**
```javascript
// ❌ 不好的做法 - 读写交替，触发多次重排
element.style.width = '100px';      // 写
console.log(element.offsetWidth);    // 读（强制重排）
element.style.height = '100px';     // 写
console.log(element.offsetHeight);   // 读（强制重排）

// ✅ 好的做法 - 批量写，批量读
// 先写
element.style.width = '100px';
element.style.height = '100px';

// 后读
console.log(element.offsetWidth);
console.log(element.offsetHeight);
```

### 5. **使用transform代替位置属性**
```javascript
// ❌ 不好的做法 - 触发重排
element.style.top = '100px';
element.style.left = '100px';

// ✅ 好的做法 - 只触发合成（Composite）
element.style.transform = 'translate(100px, 100px)';
```

### 6. **使用opacity代替visibility**
```javascript
// ❌ 触发重绘
element.style.visibility = 'hidden';

// ✅ 只触发合成（GPU加速）
element.style.opacity = '0';
```

### 7. **脱离文档流**
```javascript
// 对于大量需要修改的元素，可以暂时脱离文档流
const element = document.getElementById('complex-element');

// 方法1：设置display:none
element.style.display = 'none';
// 进行多次修改...
element.style.width = '200px';
element.style.height = '200px';
element.style.margin = '10px';
// 修改完成后恢复
element.style.display = 'block';

// 方法2：使用绝对定位
element.style.position = 'absolute';
// 进行修改...
element.style.position = 'static';
```

### 8. **动画优化**
```javascript
// ❌ 不好的做法 - 使用JavaScript动画
function animate() {
  let pos = 0;
  const element = document.getElementById('box');
  function frame() {
    pos++;
    element.style.top = pos + 'px';  // 触发重排
    if (pos < 100) requestAnimationFrame(frame);
  }
  frame();
}

// ✅ 好的做法 - 使用CSS动画
.box {
  transition: transform 0.3s ease;
}
.box.move {
  transform: translateY(100px);
}

// ✅ 或者使用Web Animations API
element.animate([
  { transform: 'translateY(0px)' },
  { transform: 'translateY(100px)' }
], {
  duration: 300,
  easing: 'ease'
});
```

### 9. **使用will-change提示浏览器**
```javascript
// 提前告知浏览器元素将要变化
element.style.willChange = 'transform, opacity';

// 动画结束后移除
element.addEventListener('animationend', () => {
  element.style.willChange = 'auto';
});
```

### 10. **虚拟滚动（Virtual Scrolling）**
对于长列表，只渲染可视区域的内容：
```javascript
// 使用虚拟滚动库，如react-window、vue-virtual-scroller等
// 示例概念
class VirtualScroll {
  render() {
    const start = Math.floor(scrollTop / itemHeight);
    const end = start + visibleCount;
    // 只渲染 start 到 end 的元素
    return visibleItems;
  }
}
```

## 三、性能监控

### 使用Performance API监测
```javascript
// 监测重排重绘
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    if (entry.entryType === 'layout-shift') {
      console.log('重排:', entry);
    }
  }
});

observer.observe({ entryTypes: ['layout-shift', 'paint'] });
```

## 四、总结

### 核心优化原则：
1. **批量操作**：将多次DOM操作合并为一次
2. **读写分离**：避免在循环中交替读写布局属性
3. **使用现代CSS**：优先使用transform、opacity等只触发合成的属性
4. **避免强制同步布局**：注意offsetWidth等属性的读取时机
5. **减少DOM层级**：越深的DOM树，重排成本越高
6. **使用事件委托**：减少事件监听器数量

通过这些优化方法，可以显著减少浏览器的重排和重绘，提升页面性能，特别是对于动画和复杂交互的场景。
