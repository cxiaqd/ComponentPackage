## 核心要点解析

### 1. 流式布局的实现

```css
/* 基础流式：宽度占满父容器，但有最大限制 */
.container {
    max-width: 1200px;
    width: 100%;
}

/* 网格采用 flex + wrap，自动换行 */
.grid {
    display: flex;
    flex-wrap: wrap;
    gap: 24px;
}

/* 卡片宽度随断点变化 */
.card {
    width: 100%;                    /* 移动端基础宽度 */
}

@media (min-width: 768px) {
    .card {
        width: calc(50% - 12px);    /* 平板端 2 列 */
    }
}

@media (min-width: 1024px) {
    .card {
        width: calc(33.333% - 16px); /* 桌面端 3 列 */
    }
}
```

**关键点**：
- 使用百分比 + `calc()` 精确计算列宽
- 媒体查询按断点调整列数
- `flex-wrap: wrap` 实现自动换行

---

### 2. 弹性媒体的实现

#### 图片弹性
```css
.card-image img {
    width: 100%;      /* 宽度占满父容器 */
    height: auto;     /* 高度自动，保持比例 */
    display: block;
}
```

#### 视频/iframe 弹性（16:9 比例容器）
```css
.video-container {
    position: relative;
    width: 100%;
    padding-bottom: 56.25%;  /* 9 / 16 = 0.5625 */
    height: 0;
    overflow: hidden;
}

.video-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;   /* 填充父容器宽度 */
    height: 100%;  /* 填充父容器高度 */
}
```

**为什么 padding-bottom 能实现固定比例？**
- `padding` 的百分比值是相对于父元素的宽度计算的
- 设置 `padding-bottom: 56.25%` 即创建了一个高度为父容器宽度 56.25% 的区域
- 子元素使用绝对定位填充这个区域

---

### 3. 响应式字体

```css
.header h1 {
    font-size: clamp(24px, 5vw, 40px);
    /* 最小 24px，理想值 5vw，最大 40px */
}
```

`clamp()` 函数让字体在移动端不会太小，在桌面端不会太大。
clamp() 函数接收三个用逗号分隔的表达式作为参数，按最小值、首选值、最大值的顺序排列。
当首选值比最小值要小时，则使用最小值。
当首选值介于最小值和最大值之间时，用首选值。
当首选值比最大值要大时，则使用最大值。
