我们来逐步分析这段代码的执行过程。

---

## 1. 定义 `partial` 函数

```javascript
function partial(fn, ...preset) {
  return function(...later) {
    return fn.apply(this, preset.concat(later));
  };
}
```
```javascript
const log = (level, timestamp, message) => {
  console.log(`[${level}] ${timestamp}: ${message}`);
};

const infoLog = partial(log, 'INFO', new Date().toISOString());
infoLog('User logged in');
```

`partial` 接收一个函数 `fn` 和任意数量的预设参数 `preset`，返回一个新函数。这个新函数在调用时，会将剩余的 `later` 参数与 `preset` 合并，并通过 `apply` 调用原函数，保留调用时的 `this` 上下文。

---

## 2. 创建 `log` 函数

```javascript
const log = (level, timestamp, message) => {
  console.log(`[${level}] ${timestamp}: ${message}`);
};
```

`log` 是一个箭头函数，它期望三个参数：`level`、`timestamp`、`message`。注意箭头函数没有自己的 `this`，它使用定义时的词法作用域 `this`。但在本例中，我们并不关心 `this`，因为调用时只是打印。

---

## 3. 调用 `partial(log, 'INFO', new Date().toISOString())`

### 3.1 传入参数
- `fn` 被绑定为 `log` 函数。
- `...preset` 收集了两个参数：`'INFO'` 和 `new Date().toISOString()`（假设当时生成的时间字符串，例如 `'2026-03-22T10:30:00.000Z'`）。
- 注意 `new Date().toISOString()` 在调用 `partial` 时**立即计算**，得到一个固定的字符串。

### 3.2 返回一个新函数
`partial` 返回一个函数，我们可以理解为：

```javascript
function(later) {
  return log.apply(this, ['INFO', timestampString].concat(later));
}
```

这个新函数被赋值给 `infoLog`。

此时 `infoLog` 是一个闭包，它记住了：
- 被柯里化的原函数 `log`
- 预设参数数组 `['INFO', timestampString]`

---

## 4. 调用 `infoLog('User logged in')`

### 4.1 参数传递
`infoLog` 被调用时，传入一个参数 `'User logged in'`。在返回的函数体内：
- `later` 是 `['User logged in']`
- `preset` 是外层闭包中的 `['INFO', timestampString]`
- `preset.concat(later)` 得到 `['INFO', timestampString, 'User logged in']`

### 4.2 调用 `log.apply(this, args)`
- `apply` 的第一个参数 `this`：由于 `infoLog` 是作为一个普通函数调用的（没有通过对象调用，也没有 `bind`），`this` 在非严格模式下是全局对象（浏览器中是 `window`，Node.js 中是 `global`），在严格模式下是 `undefined`。但 `log` 是一个箭头函数，它不关心 `this`，所以这个 `this` 值对实际行为无影响。
- `args` 是 `['INFO', timestampString, 'User logged in']`。

### 4.3 执行 `log`
`log` 接收到三个参数：
- `level = 'INFO'`
- `timestamp = timestampString`（例如 `'2026-03-22T10:30:00.000Z'`）
- `message = 'User logged in'`

然后执行 `console.log`，输出类似：
```
[INFO] 2026-03-22T10:30:00.000Z: User logged in
```

---

## 5. 关键点总结

- **`partial` 调用时**：预设参数（包括时间戳）就已经被固定下来。因此 `infoLog` 每次调用都会使用同一个时间戳，不会重新获取当前时间。如果需要动态获取时间戳，应该把 `new Date().toISOString()` 的调用放在 `infoLog` 内部或通过剩余参数传递。
- **闭包**：`infoLog` 函数保留了 `preset` 数组，该数组在创建时就已经确定。
- **参数合并**：使用 `concat` 将预设参数和剩余参数合并成完整的参数列表。
- **`this` 传递**：通过 `apply(this, ...)` 保持了调用时的 `this` 上下文，使得 `partial` 返回的函数可以被用作对象方法等场景。

---

## 6. 如果想让时间戳每次调用时动态获取

可以将时间戳的生成推迟到调用时，比如：

```javascript
const infoLog = (...messages) => log('INFO', new Date().toISOString(), ...messages);
// 或使用 partial 但不预设时间戳
const infoLog = partial(log, 'INFO');
infoLog(new Date().toISOString(), 'User logged in');
```

但在这个例子中，`partial` 的用法只是展示如何固定部分参数。
