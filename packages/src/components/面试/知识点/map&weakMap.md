`Map` 和 `WeakMap` 是 JavaScript 中两种不同的键值对集合，它们的核心区别在于**键的引用方式**和**垃圾回收机制**。下面从几个方面对比说明：

---

### 1. 键的类型
- **Map**：键可以是**任意类型**，包括对象、原始值（字符串、数字等）。
- **WeakMap**：键**只能是对象**（或 `Symbol`，但通常只讨论对象），不能是原始值。

---

### 2. 垃圾回收
- **Map**：对键是**强引用**。即使键对象不再被其他地方引用，只要它还在 `Map` 中，就不会被垃圾回收，可能导致内存泄漏。
- **WeakMap**：对键是**弱引用**。如果键对象不再被其他地方引用，它会被自动垃圾回收，同时该键值对会从 `WeakMap` 中消失。

---

### 3. 可枚举性
- **Map**：是可迭代的，支持 `size` 属性、`forEach`、`keys()`、`values()`、`entries()` 等方法，可以遍历所有键值对。
- **WeakMap**：**不可迭代**，没有 `size` 属性，也没有遍历方法（如 `keys`、`values`）。这是为了避免在垃圾回收过程中暴露不确定的键集合。

---

### 4. 方法
| 方法            | Map          | WeakMap      |
|----------------|--------------|--------------|
| `set(key, value)` | ✅           | ✅           |
| `get(key)`        | ✅           | ✅           |
| `has(key)`        | ✅           | ✅           |
| `delete(key)`     | ✅           | ✅           |
| `clear()`         | ✅           | ❌           |
| `size` 属性       | ✅           | ❌           |
| 遍历方法（`forEach`、`keys`等） | ✅ | ❌ |

---

### 5. 使用场景
- **Map**：适合存储需要遍历、统计大小或键类型多样的数据，如缓存、全局状态管理。
- **WeakMap**：主要用于**避免内存泄漏**的场景，例如：
  - 存储与 DOM 元素相关的私有数据（当 DOM 元素被移除时，数据自动释放）。
  - 在类中实现私有属性（通过以实例为键，存储私有数据）。
  - 缓存临时对象，但不想阻止其被回收。

---

### 示例对比

```javascript
// Map：强引用，键对象不会被回收
let obj = { name: "Alice" };
let map = new Map();
map.set(obj, "some data");
obj = null; // 仍然可以通过 map.keys() 访问原对象，内存未释放

// WeakMap：弱引用，键对象可被回收
let wm = new WeakMap();
let obj2 = { name: "Bob" };
wm.set(obj2, "some data");
obj2 = null; // 键对象失去引用，会被垃圾回收，键值对自动消失
```

---

### 总结
- **Map**：功能全面，适合常规缓存、存储结构。
- **WeakMap**：牺牲遍历能力，换取自动内存管理，适合与对象生命周期绑定的数据存储。
