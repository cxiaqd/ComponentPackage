Vue 2 中的自定义指令允许你直接操作 DOM，实现一些底层或复用的交互行为。下面从定义方式、钩子函数、参数以及一个典型示例来介绍。

---

## 一、自定义指令的定义

自定义指令可以**全局注册**或**局部注册**。

### 1. 全局注册
```javascript
// main.js 或入口文件
Vue.directive('focus', {
  // 指令的钩子函数
  inserted(el) {
    el.focus()
  }
})
```

### 2. 局部注册
在组件中使用 `directives` 选项：
```javascript
export default {
  directives: {
    focus: {
      inserted(el) {
        el.focus()
      }
    }
  }
}
```

---

## 二、钩子函数

Vue 2 的自定义指令提供了 5 个钩子函数（均为可选）：

| 钩子函数 | 触发时机 |
|---------|--------|
| `bind` | 只调用一次，指令第一次绑定到元素时调用。可在此进行一次性初始化设置。 |
| `inserted` | 被绑定元素插入父节点时调用（仅保证父节点存在，但不一定已被插入文档）。 |
| `update` | 所在组件的 VNode 更新时调用，**可能发生在其子 VNode 更新之前**。指令的值可能发生了改变，也可能没有。 |
| `componentUpdated` | 所在组件的 VNode **及其子 VNode** 全部更新后调用。 |
| `unbind` | 只调用一次，指令与元素解绑时调用。 |

---

## 三、钩子函数的参数

每个钩子函数都可以接收以下参数：

- **el**：指令所绑定的元素，可以直接操作 DOM。
- **binding**：一个对象，包含以下属性：
  - `name`：指令名，不包括 `v-` 前缀。
  - `value`：指令的绑定值。例如 `v-my-directive="1 + 1"` 中，值为 `2`。
  - `oldValue`：仅在 `update` 和 `componentUpdated` 中可用，指之前的绑定值。
  - `expression`：字符串形式的指令表达式。例如 `v-my-directive="1 + 1"` 中，表达式为 `"1 + 1"`。
  - `arg`：传给指令的参数（可选）。例如 `v-my-directive:foo` 中，`arg` 为 `"foo"`。
  - `modifiers`：一个包含修饰符的对象。例如 `v-my-directive.foo.bar` 中，`modifiers` 为 `{ foo: true, bar: true }`。
- **vnode**：Vue 编译生成的虚拟节点。
- **oldVnode**：上一个虚拟节点，仅在 `update` 和 `componentUpdated` 中可用。

## 四、一个完整的示例：自动聚焦输入框

**需求**：页面加载后让输入框自动获得焦点。

### 1. 定义指令（全局）
```javascript
// 注册一个全局自定义指令 `v-focus`
Vue.directive('focus', {
  // 当绑定元素插入到 DOM 中时
  inserted: function (el) {
    el.focus()
  }
})
```

### 2. 使用指令
```html
<input v-focus>
```

### 3. 带参数和修饰符的指令示例：颜色切换

假设有一个 `v-color` 指令，可以接收颜色值，并带一个 `delay` 修饰符。

```javascript
Vue.directive('color', {
  bind(el, binding) {
    // 如果修饰符有 delay，则延迟改变颜色
    if (binding.modifiers.delay) {
      setTimeout(() => {
        el.style.color = binding.value
      }, 1000)
    } else {
      el.style.color = binding.value
    }
  },
  update(el, binding) {
    // 当值变化时，更新颜色
    el.style.color = binding.value
  }
})
```

使用：
```html
<p v-color.delay="'red'">这段文字一秒钟后变红</p>
<p v-color="'blue'">立即变蓝</p>
```

## 五、注意事项

1. **指令钩子参数是只读的**，不要修改它们（如 `binding` 对象）。
2. 在 `bind` 和 `update` 时，元素可能尚未插入 DOM，因此某些 DOM 操作（如 `focus`）建议放在 `inserted` 中。
3. 如果只需要在值变化时执行操作，通常将逻辑写在 `update` 或 `componentUpdated` 中，但注意 `update` 可能在子 VNode 更新前调用，因此 DOM 状态可能尚未最终确定。
4. 指令内部可以访问 `this`，但 `this` 指向指令对象本身，而非组件实例。若需要访问组件实例，可通过 `vnode.context` 获取。
5. 对于频繁使用的 DOM 操作，使用自定义指令可以很好地复用代码，但避免过度使用，优先考虑组件化。

## 六、动态指令参数（Vue 2.6.0+）

从 Vue 2.6.0 开始，指令的参数可以是动态的。例如：

```html
<div v-pin:[direction]="200">Sticky</div>
```

```javascript
Vue.directive('pin', {
  bind(el, binding) {
    const position = binding.arg   // 动态参数
    el.style[position] = binding.value + 'px'
  }
})
```

---

## 七、对象字面量传值

如果需要传递多个值，可以使用对象字面量：

```html
<div v-demo="{ color: 'white', text: 'hello!' }"></div>
```

```javascript
Vue.directive('demo', function (el, binding) {
  console.log(binding.value.color) // => "white"
  console.log(binding.value.text)  // => "hello!"
})
```

自定义指令是 Vue 2 中处理底层 DOM 操作的利器，合理使用能让代码更优雅、复用性更强。
