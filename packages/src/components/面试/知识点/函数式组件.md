在 Vue 中，**函数式组件**是一种没有实例状态（即无 `data`、无 `this`）、没有生命周期钩子的组件。它本质是一个**纯函数**，接收 `props` 和 `context` 参数，返回虚拟节点（VNode）。因其无状态、无实例的特性，渲染开销极低，适合用于**纯展示型组件**或**高阶组件**。

---

## 一、为什么需要函数式组件？

- **性能优势**：没有组件实例化过程（无需创建 `this`、响应式数据等），渲染速度更快。
- **简洁**：代码更轻量，只关心传入的 `props` 和渲染逻辑。
- **作为包装器**：常用于封装通用逻辑（如权限控制、动态组件选择），不需要维护自身状态。

---

## 二、Vue 2 中的函数式组件

### 1. 两种定义方式

#### 方式一：`functional: true` 选项（单文件组件）
```vue
<template functional>
  <div class="card">
    <h3>{{ props.title }}</h3>
    <slot />
  </div>
</template>

<script>
export default {
  functional: true,
  props: ['title']
}
</script>
```

#### 方式二：JSX / `render` 函数
```js
export default {
  functional: true,
  props: ['title'],
  render(h, context) {
    // context 包含：props, children, slots, data, parent, listeners, injections
    return h('div', context.data, [
      h('h3', context.props.title),
      context.children
    ])
  }
}
```

### 2. 关键点
- 没有 `this`，所有信息通过 `context` 参数传递。
- `context` 包含：
  - `props`：传入的属性
  - `children`：VNode 子节点数组
  - `slots`：返回所有插槽的函数
  - `data`：传递给组件的整个数据对象（`attrs`、`class`、`style`、`on` 等）
  - `parent`：父组件实例
  - `listeners`：事件监听器（在 Vue 2 中，`listeners` 需手动传递）
- 可以接收 `props`，但不会自动将非 `props` 属性透传（需手动处理）。

---

## 三、Vue 3 中的函数式组件

Vue 3 保留了函数式组件，但官方**推荐优先使用普通组件**，原因如下：
- 性能差距已缩小（Vue 3 的普通组件实例化开销大幅降低）。
- 组合式 API 提供了更好的逻辑复用方式，函数式组件的“包装器”场景可被普通组件替代。
- 函数式组件在 Vue 3 中写法有变化。

### 1. Vue 3 中的定义方式

#### 方式一：`functional` 属性（仍支持，但不推荐）
```vue
<template functional>
  <div>{{ props.msg }}</div>
</template>
```

#### 方式二：纯函数（推荐用于简单场景）
```js
import { h } from 'vue'

const FunctionalComponent = (props, context) => {
  return h('div', props.msg)
}

FunctionalComponent.props = ['msg']
```

#### 方式三：JSX
```jsx
const FunctionalComponent = (props, { slots }) => {
  return <div>{props.msg}{slots.default?.()}</div>
}
FunctionalComponent.props = ['msg']
```

### 2. Vue 3 中的 `context` 变化
Vue 3 中函数式组件的第二个参数 `context` 包含：
- `attrs`：非 `props` 属性
- `emit`：触发事件的方法
- `slots`：插槽函数

没有 `children` 属性（改用 `slots.default()`）。

---

## 四、使用场景

- **展示型组件**：如 `Button`、`Card`、`Badge`，仅根据 `props` 渲染 UI。
- **动态组件选择器**：根据条件渲染不同组件，无需内部状态。
- **高阶组件**：对组件进行包装、添加样式或额外逻辑，但不引入实例。
- **列表项组件**：在大列表中渲染大量简单项时，可减少内存占用。

---

## 五、与 React 函数式组件的对比

| 特性 | Vue 函数式组件 | React 函数式组件 |
|------|----------------|------------------|
| **状态管理** | 无内部状态（不能使用 `ref`、`reactive`） | 可使用 Hooks（`useState`、`useEffect` 等） |
| **实例** | 无 `this`，无组件实例 | 有实例（但通过 Hooks 管理） |
| **性能** | 极低开销（无响应式代理） | 与普通组件无明显差距 |
| **生命周期** | 无 | 通过 Hooks 模拟 |
| **定位** | 轻量纯渲染组件 | 现代 React 的默认组件形态 |

---

## 六、最佳实践建议

- **Vue 2**：函数式组件是性能优化的有效手段，可用于高频渲染的静态组件。
- **Vue 3**：除非对性能有极致要求（如大型表格每行数千次渲染），否则**优先使用普通组件 + 组合式 API**，代码更易维护和扩展。
- 如果需要逻辑复用，自定义指令或组合式函数通常比函数式组件更合适。

---

## 七、示例：一个函数式按钮组件

```vue
<!-- Vue 2 -->
<template functional>
  <button
    :class="['btn', `btn-${props.type}`]"
    :disabled="props.disabled"
    v-on="listeners"
  >
    <slot />
  </button>
</template>

<script>
export default {
  functional: true,
  props: {
    type: { type: String, default: 'primary' },
    disabled: Boolean
  }
}
</script>
```

在 Vue 3 中，若仍想使用函数式组件，可这样实现：
```js
import { h } from 'vue'

export default function Button(props, { slots, attrs }) {
  return h('button', {
    class: ['btn', `btn-${props.type}`],
    disabled: props.disabled,
    ...attrs
  }, slots.default?.())
}

Button.props = {
  type: { type: String, default: 'primary' },
  disabled: Boolean
}
```

---

## 总结

Vue 中的函数式组件是轻量级的无状态组件，在 Vue 2 中是性能优化利器，在 Vue 3 中仍可用但已不再是推荐的主流写法。现代 Vue 开发更倾向于使用普通组件 + 组合式 API 来兼顾性能与开发体验。如果遇到高频渲染或纯包装场景，函数式组件依然是一个可靠的选择。
